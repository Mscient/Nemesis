# Plan-First Skill

Before any change that touches > 2 files or introduces a new feature:

1. **Print a short numbered checklist** of what you'll create/modify.
2. **Confirm the plan** with the user (or proceed if the instruction is unambiguous).
3. **Execute step by step**, checking off each item.
4. **Verify** each step works before moving to the next.

## Checklist Template
```
Plan:
- [ ] Create X
- [ ] Modify Y to add Z
- [ ] Register in W
- [ ] Run `make test` to verify
```

## When to skip planning
- Single-file changes (typos, small tweaks)
- Explicitly told "just do it"
