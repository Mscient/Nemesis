# StockSense

> **Adaptive Inventory Replenishment Engine** — Hackathon prototype.

## Quick Start (5 commands)

```bash
git clone <repo>
cd stocksense
cp .env.example .env          # edit LLM_API_KEY if you want AI features
python data/generate_synthetic.py   # create sample data
docker compose up --build
```

Open **http://localhost:5173** → upload `data/sample/sales.csv`.  
API docs at **http://localhost:8000/docs**.

## Local dev (no Docker)

```bash
# Core
cd core && pip install -e .
# AI layer
cd ../ai && pip install -e .
# Backend
cd ../backend && pip install -r requirements.txt
AI_ENABLED=false uvicorn app.main:app --reload
# Frontend
cd ../frontend && npm install && npm run dev
```

## Running tests

```bash
cd core && pytest           # mandatory spec-fixture tests
cd backend && pytest        # API contract + integration tests
cd ai && pytest             # AI guardrail tests
cd frontend && npm test     # Vitest component tests
```

## Architecture

```
frontend (React+Vite+TS)
    │ REST / JSON (snake_case)
backend (FastAPI + Pydantic v2)
    ├── core (stocksense_core) — all inventory math
    └── ai  (stocksense_ai)   — LLM suggestions only
```

See [`docs/API.md`](docs/API.md) for the full endpoint reference.

> **Note:** Sample data is **SYNTHETIC** — generated by `data/generate_synthetic.py`.
